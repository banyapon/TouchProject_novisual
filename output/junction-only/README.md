# สี่แยก: เส้นเดียว ใช้ได้สองทิศทาง

ถนนหลัก 1=ล่าง, 2=บน, 3=ซ้าย, 4=ขวา

| ID ใน JSON | ป้ายในภาพ | การเดินทาง |
|---|---|---|
| 5 | 1-3 | 1↔3 |
| 6 | 1-4 | 1↔4 |
| 7 | 2-3 | 2↔3 |
| 8 | 2-4 | 2↔4 |

รวม 8 ID: ถนนหลัก 4 เส้น และเส้นเลี้ยว 4 เส้น ขาไป–กลับใช้ ID และพิกัดเส้นเดียวกัน ไม่มี reverseRoad หรือข้อจำกัดทางเดียว ทางตรง 1↔2 และ 3↔4 เชื่อมโดยตรง ไม่เพิ่ม ID

ป้าย 1-3 หมายถึงเส้นร่วมระหว่างถนน 1 กับถนน 3 ส่วน id และ roadNo ใน JSON ยังคงเป็นเลขจำนวนเต็มเพื่อรักษารูปแบบข้อมูลเดิม

## การเลือกทิศ

- enterNode: 0 เข้า S แล้ววิ่งไป E
- enterNode: 1 เข้า E แล้ววิ่งไป S
- ทุกเส้นมี bidirectional: true ทิศที่วิ่งเป็นสถานะของรถ ไม่ใช่ข้อจำกัดของเส้น
- ลูกศรเหลืองและเขียวในภาพแสดงสองทิศทางบนโค้งเส้นเดียว directionColors เป็นข้อมูลแสดงผลเท่านั้น

ตัวอย่าง ID 5 (1-3): จากถนน 1 เข้า S และออก E ไปถนน 3; จากถนน 3 เข้า E และออก S ไปถนน 1 ใช้ ID 5 เดิมทั้งสองทิศ

junction_connections.json เป็นข้อมูลการเชื่อมต่อแบบกระชับ ส่วน junction.json เพิ่มพิกัดเส้นและช่วงต่อทางตรง junction.svg และ junction_512.png แสดงป้ายเดียวต่อเส้นตามข้อมูลชุดนี้

ปลายนอกทั้งสี่เป็นขอบเขตเปิด: node ว่างและ defaultRoad=0 หมายถึงไม่มีถนนถัดไป ชุดไฟล์นี้ยังไม่ได้ติดตั้งแทนแผนที่ Unity; การนำเข้าต้องสร้าง spline ให้ตรงกับพิกัดและจำนวนถนน 8 เส้น

รัน python output/junction-only/build_junction.py เพื่อตรวจและสร้าง JSON/SVG ใหม่ การตรวจครอบคลุม ID ไม่ซ้ำ ปลายเชื่อมกลับได้ พิกัดปลายตรงกัน ไม่มีเส้นกลับซ้ำ และทางออกจากแต่ละแขนครบทั้งสามทาง
